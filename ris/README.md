# RIS / D-RIS — Reverse Influence Sampling Algorithm

Python implementation of the D-RIS algorithm for influence maximization.

Based on:

> **"Influence Maximization Algorithm Based on Reverse Reachable Set"**
> Gengxin Sun, Chih-Cheng Chen
> *Mathematical Problems in Engineering*, Hindawi, 2021
> DOI: 10.1155/2021/5535843

Also builds on the foundational RIS framework from:

> **"Maximizing Social Influence in Nearly Optimal Time"**
> Christian Borgs, Michael Brautbar, Jennifer Chayes, Brendan Lucier — *SODA 2014*

---

## What This Is

The greedy and CELF algorithms for influence maximization rely on repeated Monte Carlo simulations — making them slow on large-scale networks. The RIS (Reverse Influence Sampling) family takes a fundamentally different approach: instead of simulating forward propagation from seed nodes, it samples **Random Reverse Reachable (RRR) sets** and selects seeds that cover the most RRR sets.

The D-RIS algorithm improves upon basic RIS by introducing an **automatic debugging method** to dynamically determine the critical number of RRR sets (θ). This avoids both under-sampling (poor approximation) and over-sampling (wasted computation).

> D-RIS is close to CELF in influence propagation range and significantly better than CELF and RIS in running time — making it more suitable for large-scale social networks.

---

## Key Concept — Random Reverse Reachable Sets

A **Reverse Reachable (RR) set** for node v is generated by:
1. Sampling a graph g from G — keep edge (u→v) with probability p(u,v)
2. Finding all nodes in g that have a directed path to v (backward BFS from v)

A **Random RRR set** is a RR set for a uniformly random node v.

**Key Lemma (Borgs et al. 2014):**
> The probability that a diffusion from seed set S activates node v equals the probability that at least one node in S appears in a RR set for v.

This means: a seed set covering many RRR sets has high expected influence spread. The fraction of RRR sets covered by S is an **unbiased estimator** of σ(S) / n.

## D-RIS Algorithm

```
1. Initialize theta_0 = n * ln(n) / k

2. Generate theta_0 RRR sets:
   R = { RRR_1, ..., RRR_{theta_0} }
   Each RRR_i:
     a. Select node v uniformly at random
     b. BFS backward from v in sampled graph g
        (keep edge u→v with prob p[u][v])
     c. Return ancestor set of v in g

3. Estimate OPT from coverage:
   Run greedy coverage on R to get best k nodes
   OPT_est = (fraction of R covered) * n

4. Recompute theta using OPT_est (tighter bound):
   theta_new = n * (8+2ε) * (l*ln(n) + ln(C(n,k)) + ln(2)) / (ε² * OPT_est)

5. Generate additional RRR sets if theta_new > |R|

6. Greedy maximum coverage on final R:
   For i = 1 to k:
     u* = node appearing most often in R
     S.append(u*)
     R = R \ {RRR ∈ R : u* ∈ RRR}

7. Return S
```

**Approximation guarantee:** σ(S) ≥ (1 − 1/e − ε) · OPT with probability ≥ 1 − n^(−l)

## Algorithms Implemented

| Algorithm | Description | Complexity |
|-----------|-------------|-----------|
| D-RIS | Dynamic RIS with automatic θ (Sun & Chen 2021) | O(θ_dyn × avg_RRS + k × θ) |
| RIS | Basic RIS with fixed θ (Borgs et al. 2014) | O(θ × avg_RRS + k × θ) |
| CELF | Lazy-forward greedy (Leskovec et al. 2007) — baseline | O(N × MC + small × k × MC) |

## Datasets

Both from [Stanford SNAP](https://snap.stanford.edu/data/index.html):

| Dataset | SNAP file | Nodes | Edges | Description |
|---------|-----------|-------|-------|-------------|
| Slashdot | soc-Slashdot0902.txt | 82,168 | 948,464 | Slashdot Zoo social network (Feb 2009) |
| Epinions | soc-Epinions1.txt | 75,879 | 508,837 | Directed Epinions trust network |

**Probability model:**
- `IC` — Uniform IC: `p(u,v) = 0.01` for all edges (default for large networks)
- `WC` — Weighted Cascade: `p(u,v) = 1 / in_degree(v)`

## How to Run

```bash
# D-RIS on Slashdot, k=50 seeds, ε=0.5
python experiments.py slashdot --k 50 --eps 0.5

# D-RIS on Epinions
python experiments.py epinions --k 50 --eps 0.5

# Quick test on a 2000-node subgraph
python experiments.py slashdot --sub 2000 --k 20

# Compare D-RIS vs RIS vs CELF (CELF is slow — use --sub for large graphs)
python experiments.py slashdot --sub 1000 --k 20 --compare

# Both datasets
python experiments.py all --k 50 --eps 0.5
```

> **Warning**: Slashdot (82k nodes, 948k edges) and Epinions (75k nodes, 508k edges) are large. Running on the full datasets requires significant memory for storing θ RRR sets. Use `--sub N` for quick testing.

## Paper's Reported Results (k=1..50)

The paper compares D-RIS against CELF, RIS, HighDegree, LIR, and pBmH on both datasets:

| Algorithm | Influence Spread | Running Time |
|-----------|-----------------|-------------|
| CELF | Highest (baseline) | Very slow |
| D-RIS | ≈ CELF | Significantly faster than CELF and RIS |
| RIS | Slightly below CELF | Faster than CELF, slower than D-RIS |
| HighDegree | Below RIS | Very fast (heuristic) |
| LIR | Below RIS | Fast (heuristic) |
| pBmH | Below RIS | Fast (heuristic) |

**Key finding:** D-RIS achieves near-CELF quality at a fraction of the computational cost, making it the preferred algorithm for large-scale networks.
