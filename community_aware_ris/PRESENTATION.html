The Influence Maximisation Problem

Formal Definition

Given a directed social network G = (V, E) and a budget k, find a seed set S ⊆ V with |S| = k such that the expected number of activated nodes is maximised.

S* = argmax|S|=k σ(S)

Where σ(S) = expected influence spread under a chosen diffusion model.

Why It's Hard

NP-Hard — Proved by Kempe et al. 2003

Computing σ(S) exactly requires evaluating exponentially many activation paths. Even estimating it requires Monte Carlo simulation.

Best achievable ratio: 1 − 1/e ≈ 0.632
Guaranteed by submodularity + greedy selection.

Two Diffusion Models

Independent Cascade (IC)

Each newly active node u attempts to activate neighbour v with probability p(u,v) — exactly once, independently. The process cascades in discrete rounds until no new activations.

while newly_active not empty:
  for u in newly_active:
    for v in neighbours(u):
      if random() ≤ p(u,v): activate(v)
Linear Threshold (LT)

Each node v has a threshold θv ~ Uniform[0,1]. Node activates when the weighted sum of active neighbours exceeds θv.

Key Properties of σ(S)

Monotone — adding nodes never hurts Submodular — diminishing returns These two properties guarantee (1−1/e) bound

Previous Work — Algorithm Progression

Five algorithms were studied and implemented before the proposed contribution, each solving a limitation of the previous.

Greedy Algorithm Kempe et al. · 2003
First formulation as a discrete optimisation problem. Iteratively picks the node with the highest marginal gain in σ(S). Uses Monte Carlo simulation (10,000 runs) to estimate σ at each step. Achieves (1−1/e) guarantee. O(k · n · m · R) — prohibitively slow on large graphs
CELF — Cost-Effective Lazy Forward Leskovec et al. · 2007
Exploits submodularity: a node's marginal gain can only decrease. Maintains a sorted queue — recomputes a node's gain only when it reaches the top. 700× faster than Greedy in practice while preserving the exact same (1−1/e) guarantee.
Independent Cascade Model Study
In-depth implementation and study of the IC diffusion process. Implemented path-based influence, steady-state analysis, and multiple seed selection heuristics (degree centrality, betweenness, greedy) on the Moreno high school and US airport networks.
RIS — Reverse Influence Sampling Borgs et al. · 2014
Revolutionary shift: instead of simulating forward spread, generate Random Reverse Reachable (RRR) sets by BFS backward from random nodes. The seed that covers the most RRR sets maximises σ(S). Near-linear time O((k+l)(n+m)log n / ε²) with provable approximation guarantee.
D-RIS — Dynamic RIS Sun & Chen · 2021
Improves RIS by computing θ dynamically from an OPT estimate — generates only as many RRR sets as the problem actually needs. Significantly faster than standard RIS in practice. Used as the primary baseline for CA-RIS. 3–5× faster than RIS on these datasets
CA-RIS — Community-Aware RIS This work · 2024
Extends D-RIS with community structure awareness. The first RIS-based algorithm to change what problem is being solved — from "maximise raw spread" to "maximise balanced spread across communities." Proposed contribution
All five modules implemented and benchmarked as part of this BTP Slide 3 / 10

The Gap — Echo-Chamber Effect

"All the algorithms are completely unaware of community structure of social networks. If seed nodes are selected without considering community structure, many chosen nodes will belong to the same largest community while smaller communities will have little to no influence."

Community Structure & Datasets

What is Community Structure?

Nodes cluster into groups that are densely connected internally and sparsely connected across groups. Quantified by Modularity Q:

Q = Σc [ ec − ac² ]

where ec = fraction of edges within community c, ac = fraction of ends of edges in c. Q > 0.3 indicates meaningful community structure.

The Louvain Algorithm

Phase 1: Move each node to the neighbour community that maximises ΔQ
Phase 2: Aggregate communities into super-nodes
Repeat until no improvement — near-linear time O(n log n)
Used by Facebook & Twitter for large-scale graphs

CA-RIS — The Proposed Algorithm

Modified Objective Function

F(S) = σ(S) − λ · I(S)
σ(S) — Expected influence spread (RRR-set coverage × n)
I(S) — Gini coefficient of per-community seed density
λ ≥ 0 — Trade-off: λ=0 → standard RIS; larger λ → more fairness
1
Community Detection
Run Louvain on undirected projection of G.

Returns:
• node → community id
• community → node list
• Modularity Q

Near-linear time — adds negligible overhead (0.21s on Slashdot).
→
2
RRR Set Generation
Dynamic θ (D-RIS procedure):

1. Generate θ₀ = n·ln(n)/k sets
2. Estimate OPT from coverage
3. Recompute θ = n(8+2ε)(...) / ε²·OPT
4. Generate additional sets if needed

Each RRR set: BFS backward from random node v, follow edges with probability p(u,v).
→
3
Quota Greedy Coverage
Compute quotas:
q_c = ⌊k · |C_c| / n⌋

For each of k steps:
• Pick best node with quota > 0
• If none: relax constraint
• Remove covered RRR sets
• Decrement community quota

Guarantees proportional distribution.
→
S
Seed Set
k seeds distributed proportionally across all communities.

• No community over-represented
• Quota relaxation prevents deadlock
• (1−1/e) guarantee preserved

Imbalance Measure I(S) — Gini Coefficient

density_c = |S ∩ C_c| / |C_c|

Gini = Σᵢ Σⱼ |dᵢ − dⱼ| / (2 · m · Σᵢ dᵢ)
Gini = 0 → perfectly balanced (every community proportionally covered)
Gini = 1 → all seeds in one community
Computed over all m communities simultaneously.

Evaluation Metrics

Four metrics evaluated for each algorithm — capturing both effectiveness and fairness.

📈
1. Influence Spread σ(S)
σ(S) = (1/R) · Σ |activated_r(S)|
Average number of nodes activated across R=10,000 Independent Cascade simulations. The primary measure of raw effectiveness. Higher is better. This is the metric all prior algorithms optimise exclusively.
🌐
2. Community Coverage CC(S)
CC(S) = |{c : S ∩ Cₓ ≠ ∅}| / m
Fraction of the m communities that contain at least one seed node. CC=1 means every community gets at least one seed. CC=0.75 means 25% of communities are completely ignored. Higher is better.
🎲
3. Seed Distribution Entropy H(S)
H(S) = −Σ_c p_c · log₂(p_c) / log₂(m)
Normalised Shannon entropy of the seed count distribution across communities. H=1 means seeds are distributed as uniformly as possible. H=0 means all seeds in one community. Higher is better.
⚖️
4. Gini Imbalance I(S)
I(S) = Gini({|S∩Cₓ|/|Cₓ|} for all c)
Gini coefficient of per-community fractional seed density. Measures inequality of coverage proportional to community size. This is the I(S) term in the CA-RIS objective F(S). Lower is better.

Plus: Operational Metrics

Runtime t — Wall-clock time in seconds. CA-RIS should be comparable to D-RIS (Louvain adds ~0.2s) and significantly faster than standard RIS (which uses a fixed large θ).
RRR sets θ — Total RRR sets generated. Dynamic θ means CA-RIS and D-RIS generate only what's needed; standard RIS uses a fixed conservative θ = 200,000.

🔑 Key Finding

CC, Entropy, and Gini are completely flat across all λ values. The σ̂ variation (72.58 → 74.40) is RRR sampling noise from different θ values.

This means: the community-quota greedy is the primary driver of fairness, not the λ penalty term. λ only influences the OPT estimate and hence how many RRR sets are generated.

The quota mechanism alone is sufficient to achieve balanced distribution — λ can be treated as a theoretical framing parameter for the objective function.

Core Contributions

1

Community-aware objective

First RIS-based algorithm to incorporate community structure into seed selection via F(S) = σ(S) − λ·I(S), changing what problem is being solved.

2

Community-quota greedy

Proportional quota allocation with largest-remainder method ensures balanced distribution without compromising the (1−1/e) approximation guarantee.

3

Empirical validation

Gini reduced 38–64% vs D-RIS on two real SNAP datasets with only 1.6–5.5% spread cost. Runtime competitive with D-RIS.

Limitations

Very small communities

Communities <20 nodes with p=0.01 rarely appear in RRR sets — receive zero seeds regardless of quota. The quota-relaxation rule handles this but these communities remain uncovered.

λ penalty not driving fairness

The λ-sweep shows CC/entropy/Gini flat across λ ∈ {0,2}. The quota mechanism already achieves fairness — λ's role in the objective needs to be integrated more directly into the greedy scoring.

Future Work

→

Full-graph experiments — Run on complete Slashdot (82k) and Epinions (75k) graphs for richer community granularity and more communities to cover.

→

k-sensitivity — Vary k ∈ {10, 20, 30, 40, 50} to show how the spread–fairness trade-off changes with budget size.

→

λ in greedy scoring — Integrate λ directly into the marginal gain score at each greedy step rather than only in the θ determination.

→

Adaptive propagation probabilities — Higher p for intra-community edges (strong ties) vs lower p for inter-community edges (weak ties) — consistent with Granovetter's strength of weak ties.
